
# Rooftop Solar Energy Monitoring System

## Project Description
The Rooftop Solar Energy Monitoring System is a Java-based application that calculates solar energy generation and monitors household electricity consumption. It helps users understand their energy usage, surplus electricity, and estimated daily savings.

## Objectives
- Calculate electricity generated by rooftop solar panels.
- Monitor household energy consumption.
- Identify surplus or deficit electricity.
- Estimate daily electricity cost savings.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Scanner class for user input
- Conditional statements and mathematical calculations

## Features
1. Accepts solar panel capacity.
2. Takes sunlight hours as input.
3. Calculates solar energy generation based on panel efficiency.
4. Compares generated electricity with household consumption.
5. Displays surplus or additional energy required.
6. Estimates daily electricity savings.

## Formula Used

Solar Energy Generated:

Energy = Panel Capacity × Sunlight Hours × Efficiency

Energy Balance:

Energy Balance = Energy Generated − Energy Consumed

Estimated Daily Savings:

Savings = Energy Generated × Electricity Rate

## How to Run the Project

### Step 1: Install Java
Install the Java Development Kit (JDK) on your computer.

### Step 2: Compile the Program
Open Command Prompt in the project folder and execute:

javac Main.java

### Step 3: Run the Program

java Main

### Step 4: Enter the Required Details
Enter the solar panel capacity, sunlight hours, efficiency, household consumption, and electricity rate when prompted.

## Sample Input

Panel Capacity: 5 kW
Sunlight Hours: 5
Efficiency: 0.80
Household Consumption: 15 kWh
Electricity Rate: Rs. 8 per kWh

## Limitations
- Uses manually entered data.
- Does not connect to real solar panels or sensors.
- Savings are estimates and may differ from actual electricity bill savings.
